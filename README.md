# Texture Classification | CNN with PyTorch

### Классификация текстур CUReT с помощью свёрточной нейронной сети

## О проекте

Проект посвящён разработке и обучению свёрточной нейронной сети (Convolutional Neural Network, CNN) для многоклассовой классификации текстур из датасета **CUReT (Columbia-Utrecht Reflectance and Texture Database)**.

**Цель проекта** — разработать собственную архитектуру CNN, способную классифицировать изображения текстур по 61 классу с точностью не ниже 95%.

Для решения задачи реализована нейронная сеть `TextureNetV2` на PyTorch, включающая четыре свёрточных блока, Batch Normalization, Dropout и полносвязный классификатор.

**Итоговый результат: 96,08% accuracy на тестовой выборке.**

## Данные

**Датасет:** CUReT

Используется набор изображений, содержащий:

- 61 класс текстур.
- 92 изображения в каждом классе.
- 5 612 изображений суммарно.

### Разделение данных

| Выборка | Изображений на класс | Всего |
|---|---:|---:|
| Train | 46 | 2 806 |
| Test | 46 | 2 806 |
| **Всего** | **92** | **5 612** |

Для каждого класса первые 46 изображений используются для обучения, оставшиеся 46 — для тестирования.

## Предобработка изображений

Перед обучением выполнены следующие преобразования:

1. **Grayscale conversion** — преобразование цветных изображений в оттенки серого.
2. **Resizing** — уменьшение изображений в два раза по ширине и высоте.
3. **Normalization** — масштабирование значений пикселей в диапазон [0, 1].
4. **Tensor conversion** — преобразование массивов NumPy в тензоры PyTorch.
5. **DataLoader** — организация пакетной загрузки данных.

После предобработки каждое изображение имеет размерность:

`1 × 100 × 100`

Использование одного канала позволяет снизить вычислительную сложность модели и сосредоточиться на текстурных характеристиках изображений.

## Архитектура модели

Разработана собственная архитектура **TextureNetV2**, состоящая из четырёх последовательных свёрточных блоков и полносвязного классификатора.

### Свёрточная часть

| Блок | Каналы | Операции |
|---|---|---|
| Conv Block 1 | 1 → 64 | Conv2D × 2, BatchNorm, ReLU, Dropout2D, MaxPool |
| Conv Block 2 | 64 → 128 | Conv2D × 2, BatchNorm, ReLU, Dropout2D, MaxPool |
| Conv Block 3 | 128 → 256 | Conv2D × 2, BatchNorm, ReLU, Dropout2D, MaxPool |
| Conv Block 4 | 256 → 512 | Conv2D × 2, BatchNorm, ReLU, Dropout2D, MaxPool |

Каждый свёрточный блок включает:

- Два слоя `Conv2d` с ядром 3×3.
- Batch Normalization.
- ReLU activation.
- Dropout2D (p = 0.1).
- MaxPooling2D (2×2).

### Классификатор

После свёрточных блоков используются:

- Adaptive Average Pooling.
- Fully Connected Layer: 512 → 256.
- ReLU.
- Dropout (p = 0.15).
- Output Layer: 256 → 61.

Выходной слой формирует логиты для 61 класса текстур.

## Обучение модели

Обучение проводилось на GPU **NVIDIA GeForce RTX 3050 (8 GB)**.

### Гиперпараметры

| Параметр | Значение |
|---|---|
| Optimizer | AdamW |
| Learning rate | 0.0001 |
| Weight decay | 0.01 |
| Loss function | CrossEntropyLoss |
| Label smoothing | 0.05 |
| Batch size | 16 |
| Epochs | 225 |
| Learning rate scheduler | StepLR |
| Scheduler step size | 100 |
| Scheduler gamma | 0.1 |

Для снижения риска переобучения использовались Batch Normalization, Dropout и Label Smoothing.

В процессе обучения отслеживались значения Loss и Accuracy на обучающей и тестовой выборках.

**Продолжительность обучения:** приблизительно 70 минут.
